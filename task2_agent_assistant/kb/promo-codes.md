id: promo-codes
title: Promo codes and discounts
category: billing_subscription
---
Promo codes can be applied only on the web checkout, not inside the App Store or Google Play purchase flow.

Each promo code has an expiry date and can be used once per account. Codes from partner or influencer campaigns are valid only for new subscribers.

If a valid code is rejected, ask the customer for the exact code and a screenshot of the error, and forward them to Billing. Agents cannot create new promo codes.
