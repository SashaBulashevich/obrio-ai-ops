---
id: data-privacy
title: How Nebula uses personal and birth data
category: account_privacy
---
Nebula uses birth date, time and place only to generate horoscopes, birth charts and compatibility reports.

Nebula does not sell personal data to advertisers. Data is shared only with service providers needed to run the app (hosting, payments, analytics) under data processing agreements.

The full description is available in the Privacy Policy in Profile → Settings → Legal. Customers can request a copy of their data from the Privacy team.
